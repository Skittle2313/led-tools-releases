# LED Tools – Desktop-Version

Hier liegen nur die Installer der Desktop-Version von **LED Tools** (Planung von LED-Wänden: Wände, Rigging,
Prozessor, Kabel, Output/Medienserver, Export). Die Webversion läuft unter https://led.skittle23.me.

**Herunterladen:** unter [Releases](https://github.com/Skittle2313/led-tools-releases/releases/latest) die Datei
`LED-Tools-Setup.exe` (Windows 10/11, 64 bit).

Die Installer sind nicht signiert. Windows SmartScreen fragt deshalb beim ersten Start nach
(„Weitere Informationen“ → „Trotzdem ausführen“).
